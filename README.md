## 📖 課程簡介

面對環境懸浮微粒（PM10, PM2.5, PM1）與市售各式口罩、空氣清淨機的宣傳，本課程引導國小高年級學生透過科學探究與科技自造，從「生活情境」出發，利用市售感測器與自組 Arduino 比較機進行數據收集與交叉驗證，培養學生「系統思考與解決問題（A2）」及「規劃執行與創新應變（A3）」的核心素養。

## 🎯 核心學習架構

本教案採**雙軌彈性實施**，適合不同學時需求與設備條件的學校無痛導入：

| 模式 | 涵蓋單元 | 教學時數 | 重點內容與設備 |
| :--- | :--- | :---: | :--- |
| **基礎型** | 單元一 + 單元二 | 5 節 (200分) | 探究常見濾材功能、密閉教室市售清淨機實測、Excel 折線圖統計分析 |
| **進階型** | 基礎型 + 單元三 | 8 節 (320分) | 自組 Arduino UNO + 攀藤 PMS5003 比較機、PWM 二段風速控制實測與變因分析 |

### 單元規劃

1. **單元一：濾材的種類與功能 (2 節 / 80 分鐘)**  
   - 生活情境導入（冷氣機、口罩、清淨機）、點香上升氣流初測、發現開放測量誤差。
2. **單元二：科學數據交叉驗證 (3 節 / 120 分鐘)**  
   - 密閉環境標準化檢驗、每 30 秒記錄一次濃度變化（連續 20 次取樣）、Excel 交叉比對。
3. **單元三：比較機實測過濾效能 (3 節 / 120 分鐘)**  
   - 創客硬體自造：Arduino、PMS5003、LCD1602、風速儀，控制流速探索微細粒子穿透率。

## 🛠️ 教學特色

- **低成本易推廣**：全套非商用專屬套裝教具，每組教材成本小於新台幣 1,000 元，非山非市、偏鄉學校皆可輕易複製。
- **做、用、想深度學習**：以問思引導學生發現問題並親自改進工具，自然連結 AI、大數據與物聯網概念。
- **素養導向五級評量**：訂定 A~E 級等第檢核規準，落實質性觀測與客觀數據量測。
